# Остатки этикетки — инструкция

## Как открыть

В браузере на любом компьютере офиса: `http://<адрес-сервера>:8080` (адрес скажет администратор). Входа и паролей нет.

## Как сканировать

1. Сканер должен быть настроен на «суффикс Enter». У большинства моделей это так по умолчанию. Если после скана ничего не происходит, отсканируйте настроечный штрихкод «Add Enter / CR suffix» из паспорта сканера.
2. Откройте главный экран и отсканируйте этикетку. Ставить курсор никуда не нужно, раскладка (русская или английская) не важна.
3. Если позиция есть, откроется её карточка. Если нет, появится «Штрихкод … не найден» и кнопка «Создать позицию»: форма откроется с уже заполненным штрихкодом.

## Как списать

1. В карточке курсор уже стоит в поле «Количество». Введите число и нажмите **Enter** — это «Списать».
2. Карточка закроется, внизу появится «Списано N шт., остаток M шт.». Можно сразу сканировать следующую этикетку.
3. Другие операции:
   - **Допечатка** — добавляет количество и обновляет дату печати;
   - **Инвентаризация** — в поле вводится фактический остаток.
4. **Esc** закрывает карточку без изменений.

Все изменения остатка видны на вкладке «История» в карточке.

## Если макет менялся

1. При допечатке по новому макету отметьте в карточке **«Макет менялся»** и нажмите «Добавить».
2. Весь остаток, что был до допечатки, считается старым макетом. В таблице и карточке под остатком красным написано «из них к утилизации: N».
3. Старый макет нельзя списать или переместить: списать можно только остаток без него.
4. Чтобы утилизировать старый макет: в карточке **«Заявка на утилизацию»** или через выбор позиций (см. ниже). Старый остаток списывается целиком, в истории появляется «Утилизация», подсветка пропадает.

## Заявки на перемещение и утилизацию

1. Отметьте позиции флажками в первом столбце таблицы. Выбор сохраняется при поиске и смене страницы. Флажок в заголовке выбирает всю страницу.
2. Над таблицей появится «Выбрано позиций: N» и кнопки:
   - **Заявка на перемещение** — укажите, сколько забрать по каждой позиции. Больше доступного (остаток без старого макета) указать нельзя;
   - **Заявка на утилизацию** — списывается весь старый макет. Позиции без старого макета в заявку не попадут, окно их перечислит.
3. **«Списать и распечатать»** — остаток списывается сразу по всем позициям. Если хотя бы по одной не хватает остатка, ничего не списывается, строка с ошибкой подсвечена.
4. После списания откроется печать листа заявки. Повторить — кнопка «Печать». В истории позиций будет «Перемещение» или «Утилизация».

## Как найти позицию

Строка поиска ищет по контрагенту, номеру макета и штрихкоду. Есть фильтр по контрагенту и флажок «Только нулевые». Сортировка — щелчок по заголовку столбца.

## Как добавить позицию

1. Кнопка **«Добавить»** → заполните форму → «Сохранить».
2. Если такой номер макета уже есть, новая позиция не создаётся: введённый остаток добавляется к существующей позиции. Внизу появится «Добавлено N шт. к позиции с номером макета M, остаток K шт.» с кнопкой **«Открыть»**. В истории позиции это «Допечатка» с комментарием «Совпал номер макета». Поля существующей позиции (контрагент, штрихкод, дата печати, комментарий) при этом не меняются.
3. Если штрихкод уже занят другой позицией, появится ошибка у поля и кнопка «Открыть позицию с этим штрихкодом».

## Объединение дублей по номеру макета

Кнопка **«Объединить дубли»** рядом с «Добавить» проверяет весь список активных позиций. Если найдены позиции с одинаковым номером макета, в каждой группе остаётся самая ранняя позиция: её остаток увеличивается на остатки дублей, перенос записывается в историю как «Исправление» с комментарием «Объединение дублей по номеру макета», а лишние позиции удаляются (их можно найти в разделе «Удалённые»). Если дублей нет, появится сообщение «Дубли по номеру макета не найдены».

## Как удалить и восстановить

- «Удалить» в строке таблицы → подтвердить. Сразу после удаления внизу есть кнопка **«Отменить»**.
- Позже позицию можно восстановить: ссылка **«Удалённые»** вверху → «Восстановить».
- Если номер макета или штрихкод удалённой позиции уже занят другой позицией, восстановить её не получится. Сначала освободите номер у той позиции.

## Выгрузка в Excel

Ссылка «Выгрузить в CSV» вверху. Файл открывается в Excel двойным щелчком.

## Загрузка из Excel

1. Сохраните таблицу в Excel как «CSV UTF-8» или обычный CSV. Первая строка — заголовки, как в выгрузке: «Контрагент», «№ макета», «Штрихкод», «Дата печати», «Остаток», «Комментарий». Обязательны «Контрагент», «Дата печати» и «Остаток». Проще всего взять за основу файл выгрузки.
2. Кнопка «Загрузить из CSV» вверху → выберите файл → «Проверить файл».
3. Будет показано, сколько позиций создастся и обновится, или список ошибок по строкам. Пока ошибки есть, ничего не загружается: исправьте файл и проверьте ещё раз.
4. «Загрузить» — данные записываются.

Как сопоставляются строки: по номеру макета, а если его нет — по штрихкоду. Найденная позиция обновляется, остальные создаются. Пустые ячейки не стирают то, что уже есть. Изменение остатка записывается в историю как инвентаризация с пометкой «Загрузка из CSV».

## Тёмная тема

Переключатель «Тема» вверху справа: «Как в системе», «Светлая» или «Тёмная». Выбор запоминается в этом браузере.
